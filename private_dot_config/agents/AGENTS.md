# English UI names

The user runs macOS and most applications with the English UI language. When suggesting changes to
system or application settings, always use the English names of menus, panes, options and buttons
exactly as they appear in the UI, e.g. "System Settings > Keyboard > Keyboard Shortcuts".

- Give the English name first. Add a Polish translation in parentheses only when it helps and never
  instead of the English name.
- Prefer the current macOS naming (e.g. "System Settings", not "System Preferences").
- Applies to CLI settings too: use the real English key/flag names, not translations.

# Saving tasks

The user keeps tasks in the relevant Obsidian notes, not in Google Calendar. When asked to save a
task or reminder, write it to the appropriate Obsidian note. Do not create Google Calendar events
for tasks, and do not offer Google Calendar as an option.
